ANDROID APK BUILD

EASIEST OPTION: GITHUB ACTIONS
1. Create a GitHub repository and upload all files in this project folder, including the hidden .github folder.
2. Open the repository's Actions tab.
3. Select "Build Crossmaglen Android APK" and click "Run workflow".
4. Wait for the workflow to finish successfully.
5. Download the "crossmaglen-open-world-debug-apk" artifact from the run summary.
6. Extract the downloaded ZIP and install app-debug.apk on your Android phone.

LOCAL OPTION
Requirements: Node.js 20+, Android Studio, Android SDK and JDK 21.
1. Open a terminal in this folder.
2. Run: npm install
3. Run: npx cap add android
4. Run: npx cap sync android
5. Run: npx cap open android
6. In Android Studio select Build > Build Bundle(s) / APK(s) > Build APK(s).

The debug APK is normally created at android/app/build/outputs/apk/debug/app-debug.apk.
A Play Store release requires a signed release build and signing key.
